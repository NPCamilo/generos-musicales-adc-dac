El módulo de cálculo

El proyecto no es solo una web: el motor de cálculo (nucleo/) funciona solo, sin Django, y es lo que genera el informe.

  • python -m nucleo.informe — genera el informe y las figuras.
  • python -m nucleo.comparativa — la comparación por consola.
  • python -m nucleo.descarga — baja las cinco pistas.
  • python manage.py runserver — esta aplicación web.
